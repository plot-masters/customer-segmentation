Data Cleaning

Dropping Irrelevant Columns

The drop_irrelevant_columns function removes columns that have no analytical value. This ensures the dataset remains focused on variables that contribute to downstream modeling or insights.

Removing High-Missing-Value Columns

The drop_high_missing_value_columns function eliminates columns where the proportion of missing values exceeds a specified threshold. This prevents sparsely populated fields from skewing analysis or requiring excessive imputation.

Imputing Missing Values

The impute_missing_values function fills missing entries based on column data types. Numerical fields use median imputation, categorical fields use mode, and all other types default to forward-fill. This maintains data consistency while preserving distribution characteristics.

Removing Duplicates

The remove_duplicates function removes duplicate rows and reports how many were dropped. This ensures data integrity and prevents inflated counts or biased analysis.

Handling Outliers

The handle_outliers function caps outlier values using the Interquartile Range method. Values below the lower bound or above the upper bound are replaced with the respective caps, reducing the influence of extreme values without complete removal.

Converting to Datetime

The convert_to_datetime function converts specified columns into datetime format. Invalid formats are coerced into missing values. This enables time-based operations and calculations.

Calculating Delivery Delay

The calculate_delivery_delay function computes the delay between promised and actual delivery times in minutes. It expects both fields to be datetime objects and adds a new column representing the delay duration.

Converting Categorical-Like Columns

The convert_categorical_like_columns function casts selected columns into the pandas category data type. This optimizes memory usage and clarifies the column’s semantic meaning.

Saving the Cleaned Dataset

The save_cleaned_dataset function writes the cleaned DataFrame to disk as a CSV file, prints final dataset characteristics, and returns the cleaned DataFrame for further use.

def drop_irrelevant_columns(df, irrelevant_cols):
    """Drop columns with irrelevant information."""
    for col in irrelevant_cols:
        if col in df.columns:
            df.drop(columns=[col], inplace=True)


def drop_high_missing_value_columns(df, threshold=0.5):
    """Remove columns with missing values above a certain threshold."""
    cols_to_drop = [col for col in df.columns if df[col].isnull().mean() >= threshold]
    df.drop(columns=cols_to_drop, inplace=True)


def impute_missing_values(df):
    """Impute missing values based on the data type of each column."""
    for col in df.columns:
        if df[col].dtype in ['float64', 'int64']:
            df[col] = df[col].fillna(df[col].median())
        elif df[col].dtype == 'object':
            df[col] = df[col].fillna(df[col].mode()[0])
        else:
            df[col] = df[col].ffill()


def remove_duplicates(df):
    """Remove duplicate rows."""
    before = df.shape[0]
    df.drop_duplicates(inplace=True)
    print(f"Removed {before - df.shape[0]} duplicate rows")


def handle_outliers(df, column='order_total'):
    """Handle outliers using IQR capping."""
    Q1 = df[column].quantile(0.25)
    Q3 = df[column].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR

    df.loc[df[column] < lower_bound, column] = lower_bound
    df.loc[df[column] > upper_bound, column] = upper_bound


def convert_to_datetime(df, columns):
    """Convert date/time columns to datetime."""
    for col in columns:
        if col in df.columns:
            df[col] = pd.to_datetime(df[col], dayfirst=False, errors='coerce')



def calculate_delivery_delay(df):
    """Calculate delivery delay (in minutes)."""
    df['delivery_delay_minutes'] = (df['actual_delivery_time'] -
                                    df['promised_delivery_time']).dt.total_seconds() / 60


def convert_categorical_like_columns(df, columns):
    """Convert categorical-like columns to category type."""
    for col in columns:
        if col in df.columns:
            df[col] = df[col].astype('category')


def save_cleaned_dataset(df, filename):
    """Save the cleaned dataset to a CSV file."""
    df.to_csv(filename, index=False)
    print("Data cleaning completed successfully!")
    print("Final Data Shape:", df.shape)
    print("Data Types:", df.dtypes, sep='\n')
    return df

def print_numerical_columns(df):
    """Print numerical columns with descriptive stats."""

    # Quantiles
    print("\Distribution of Spending", df[['order_total']].quantile([0.25, 0.5, 0.75, 0.95]), sep="\n")


def print_correlation(df):
    """Print correlation between numerical columns."""
    print("Correlation between order total and delivery delay in minutes",
          df[['order_total', 'delivery_delay_minutes']].corr(), sep="\n")

def print_categorical_columns(df):
    """Print categorical columns with distribution overview."""
    print("\nCategorical Columns")

    # Distribution overview of payment methods
    print("Payment Methods Distribution", df['payment_method'].value_counts(), sep="\n")

    # Distribution overview of delivery outcomes
    print("Delivery Status Distribution",

def filter_significantly_delayed_orders(df):
    """Filter and print significantly delayed orders."""
    significantly_delayed_orders = df[df['delivery_status'] == 'Significantly Delayed']
    count_delayed = significantly_delayed_orders.shape[0]
    print("Significantly delayed orders:", sep='\n')
    display(significantly_delayed_orders.head(5))
    display(count_delayed)

def generate_customer_summary(df):
    """Generate a summary table for each customer."""
    customer_summary = df.groupby('customer_id').agg({
        'order_total': 'sum',
        'order_id': 'count',
        'delivery_delay_minutes': 'mean'
    }).rename(columns={
        'order_total': 'total_spent',
        'order_id': 'order_count',
        'delivery_delay_minutes': 'avg_delivery_delay'
    }).sort_values(by='order_count', ascending=False)

    print("Summary Table for Each Customer:", sep='\n')
    display(customer_summary.head(10))

def generate_payment_method_summary(df):
    """Generate a summary table for payment methods."""
    payment_summary_df = df.groupby('payment_method', observed=True).agg({
        'order_total': 'mean',
        'order_id': 'count'
    }).rename(columns={
        'order_total': 'avg_order_value',
        'order_id': 'num_orders'
    })

    print("Payment Method Summary:")
    display(payment_summary_df)

def store_wise_order_total_by_delivery_status(df):
    """Generate a pivot table for order total by delivery status per store."""
    pivot_table = pd.pivot_table(df,
                                 index='store_id',
                                 columns='delivery_status',
                                 values='order_total',
                                 aggfunc='sum',
                                 fill_value=0,
                                 observed=False)

    print("Store-Wise Order Total by Delivery Status:")
    display(pivot_table)

def daily_sales_patterns(df):
    """Generate daily sales patterns."""
    daily_sales_df = df.set_index('order_date').resample('D').agg({
        'order_total': 'sum',
        'order_id': 'count'
    }).rename(columns={
        'order_total': 'total_sales',
        'order_id': 'num_orders'
    }).sort_index(level=1, ascending=False)

    print("Daily Sales Patterns:")
    display(daily_sales_df.head(10))

def remove_outliers_delivery_delays(df):
    """Remove outliers from delivery delays and plot the boxplot."""

    # Calculate Q1, Q3, and IQR
    Q1 = df['delivery_delay_minutes'].quantile(0.25)
    Q3 = df['delivery_delay_minutes'].quantile(0.75)
    IQR = Q3 - Q1

    # Filter out outliers
    df_cleaned = df[(df['delivery_delay_minutes'] >= (Q1 - 1.5 * IQR)) &
                    (df['delivery_delay_minutes'] <= (Q3 + 1.5 * IQR))]

    # Plot boxplot without outliers
    plt.figure(figsize=(6, 4))
    sns.boxplot(x=df_cleaned['delivery_delay_minutes'], color='lightgreen')
    plt.title("Boxplot of Delivery Delays (Outliers Removed)")
    plt.xlabel("Delivery Delay (minutes)")
    plt.show()

    return df_cleaned

Feature Engineering

Aggregating Customer Data

The aggregate_customer_data function generates a customer-level dataset by aggregating order and delivery information. It computes mean order value, total spend, order count, average delivery delay, and identifies the most frequently used payment method and most common delivery status. This transforms transactional data into customer-centric metrics suitable for modelling.

One-Hot Encoding Categorical Features

The one_hot_encode_categorical_features function converts categorical attributes (most_used_payment and most_delivery_status) into one-hot encoded variables. This prepares these fields for machine learning models that require numerical inputs while preserving categorical distinctions.

Handling Numerical Features

The handle_numerical_features function applies appropriate transformations to numeric customer-level fields:

  • Standardization of avg_order_total
  • Log transformation and standardization of total_spent to reduce skew
  • Robust scaling of avg_delay to limit the influence of outliers
  • Min-max scaling of num_orders to normalize range

These transformations enhance model performance by improving feature distribution and comparability.

End-to-End Customer Data Processing

The process_customer_data function orchestrates the complete feature engineering pipeline. It aggregates customer metrics, encodes categorical fields, applies numerical transformations, and generates diagnostic visualisations including a correlation matrix and histograms for major engineered features. It returns both the processed dataset and the untransformed customer-level dataset.

Correlation Matrix Plot

The plot_correlation_matrix function visualises the correlation structure across engineered features. The heatmap highlights relationships, multicollinearity, and potential feature redundancy.

Feature-Level Histograms

The plot_histogram function produces histograms for individual transformed features. This aids in evaluating distributional characteristics after scaling and transformation.

def aggregate_customer_data(df_cleaned):
    # Aggregating customer data
    customer_df = df_cleaned.groupby('customer_id').agg({
        'order_total': ['mean', 'sum', 'count'],
        'delivery_delay_minutes': 'mean',
        'payment_method': lambda x: x.mode()[0],
        'delivery_status': lambda x: x.mode()[0]
    }).reset_index()

    # Renaming columns
    customer_df.columns = [
        'customer_id', 'avg_order_total', 'total_spent', 'num_orders',
        'avg_delay', 'most_used_payment', 'most_delivery_status'
    ]
    return customer_df

def one_hot_encode_categorical_features(df):
    # One-hot encoding categorical features separately
    df_temp = df.copy()

    one_hot = pd.get_dummies(df_temp[['most_used_payment', 'most_delivery_status']], prefix=['payment', 'status'])
    df_final = pd.concat([df_temp.drop(columns=['most_used_payment', 'most_delivery_status']), one_hot], axis=1)

    return df_final

def handle_numerical_features(df):
    # Standardize avg_order_total
    scaler = StandardScaler()
    df['avg_order_total'] = scaler.fit_transform(df[['avg_order_total']])

    # Log transformation for total_spent to fix skewness
    df['total_spent'] = np.log1p(df['total_spent'])
    scaler = StandardScaler()
    df['total_spent'] = scaler.fit_transform(df[['total_spent']])


    # Robust scaling for avg_delay
    scaler = RobustScaler()
    df['avg_delay'] = scaler.fit_transform(df[['avg_delay']])

    # MinMax scaling for num_orders
    scaler = MinMaxScaler(feature_range=(-1, 1))
    df['num_orders'] = scaler.fit_transform(df[['num_orders']])

    return df

def process_customer_data(df_cleaned):
    customer_df = aggregate_customer_data(df_cleaned)
    customer_df_original=customer_df
    one_hot_encoded_df = one_hot_encode_categorical_features(customer_df)
    processed_df = handle_numerical_features(one_hot_encoded_df)

    # Visualizations
    plot_correlation_matrix(processed_df)
    plot_histogram(processed_df['avg_order_total'])
    plot_histogram(processed_df['total_spent'])
    plot_histogram(processed_df['avg_delay'])
    plot_histogram(processed_df['num_orders'])

    return processed_df,customer_df_original

Cluster Modelling

Executing K-Means Clustering

The perform_kmeans_clustering function runs the K-Means algorithm across multiple values of k and evaluates clustering quality. It applies PCA to reduce dimensionality for visualisation and uses three standard clustering metrics to assess performance:

  • Silhouette Score – Measures cohesion and separation of clusters.
  • Davies–Bouldin Index – Lower values indicate better-defined clusters.
  • Calinski–Harabasz Score – Higher values indicate better separation.

For each k, the function:

  1. Fits the K-Means model on PCA-reduced data.
  2. Visualises clusters in two principal components.
  3. Records performance metrics.
  4. Consolidates PCA coordinates and cluster labels for export or further analysis.

The function returns a dictionary of clustering scores and a combined DataFrame containing PCA-transformed coordinates, cluster assignments, and their corresponding k values.

Exporting Model Data

The export_model_data function saves the full cluster assignment dataset, including PCA dimensions and cluster labels, to a CSV file. This preserves the clustering output for reporting, validation, and downstream modelling workflows.

Code 
def perform_kmeans_clustering(X_scaled, k_values):
    """
    Execute kmeans clustering algorithm and log the results.

    args:
    X_scaled (DataFrame): Scaled DataFrane
    k_values (list): List of k_value to run the kmeans algorithm against.
    """

    silhouette_scores = []
    dbi_scores = []
    ch_scores = []

    cluster_data = pd.DataFrame()

    for k in k_values:
        # Perform KMeans clustering
        kmeans = KMeans(n_clusters=k, random_state=42)

        # Add cluster assignments to the original DataFrame
        # customer_df['cluster'] = clusters

        # PCA transformation
        pca = PCA(n_components=2)
        pca_data = pca.fit_transform(X_scaled)
        clusters = kmeans.fit_predict(pca_data)


        # Create a DataFrame for visualization and export
        pca_df = pd.DataFrame(pca_data, columns=['PC1', 'PC2'])
        pca_df['cluster'] = clusters
        pca_df['k'] = k

        # Plot the PCA-transformed data with clusters
        plt.figure(figsize=(8, 6))
        sns.scatterplot(data=pca_df, x='PC1', y='PC2', hue='cluster', palette='Set2')
        plt.title(f"Customer Clusters Visualized with PCA (k={k})")
        plt.show()

        # Calculate scores
        silhouette_scores.append(silhouette_score(X_scaled, clusters))
        dbi_scores.append(davies_bouldin_score(X_scaled, clusters))
        ch_scores.append(calinski_harabasz_score(X_scaled, clusters))

        # Append the current cluster data to the overall DataFrame
        if cluster_data.empty:
            cluster_data = pca_df
        else:
            cluster_data = pd.concat([cluster_data, pca_df], ignore_index=True)

    score_dict = {
        'Silhouette Scores': silhouette_scores,
        'Davies Bouldin scores':dbi_scores,
        'Calinski Harabasz Scores':ch_scores
    }

    return score_dict, cluster_data

    """
    cluster_data.to_csv(filename, index=False)
    print(f"Model data exported successfully to {filename}")

Cluster Overview

The K=2 clustering solution separates customers into one large group and one smaller group. Cluster 0 contains the majority of customers, while Cluster 1 represents a smaller segment with distinct behavioural patterns.

Cluster Characteristics

Cluster 0 Customers in this cluster place slightly more orders, spend more overall, and experience very low delivery delays. Their orders are almost always delivered on time, and the most common payment method is Card.

Cluster 1 Customers in this group make fewer purchases, spend less overall, and face significantly higher delivery delays. Most of their orders are classified as slightly delayed, and they also commonly use Card as the preferred payment method.

Behavioural Distribution

Payment method usage is similar across clusters, though Cluster 0 shows a slightly higher proportion of Card payments. Delivery performance is the strongest separator: Cluster 0 is entirely on time, whereas Cluster 1 is dominated by delayed deliveries.

Segment Interpretation

The clusters can be interpreted as:

  • On-Time High-Value Customers (Cluster 0): Higher spending, more frequent orders, consistently timely deliveries.
  • Delay-Affected Low-Value Customers (Cluster 1): Lower spending, fewer orders, and substantially higher delivery delays.

This segmentation highlights operational differences in delivery performance and their association with customer value.
